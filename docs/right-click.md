# Right-click menu

S Converter can add itself to File Explorer's right-click menu, so you can convert without any shortcut.

## Turn it on or off

The installer turns it on. Switch it off or on again in **Settings → Explorer right-click menu**.

On **Windows 11**, S Converter is under **Show more options** (or hold <kbd>Shift</kbd> while you right-click). On Windows 10 it's in the menu straight away.

## What's in the menu

Right-click a file or folder and point at **S Converter**:

| You right-click | You get |
|---|---|
| Photos | JPG, PNG, WebP, PDF, plus Email, Compress and Web presets |
| Audio | MP3, M4A, WAV, plus Voice Note |
| Video | MP4, GIF, MP3, plus Shrink and WhatsApp |
| Documents | PDF, TXT |
| PDFs | Compress, Merge, JPG |
| Folders | ZIP, 7Z, RAR, Locked ZIP |
| Archives | Extract here, Extract to a folder, convert to ZIP |
| Anything | **Quick Convert…** opens the full wheel |

The choices match what you selected, and the new files appear next to the originals.
