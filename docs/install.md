# Install and update

S Converter runs on **Windows 10 (version 1809 or newer) and Windows 11**, 64-bit. You don't need administrator rights, Microsoft Office or any other software.

## Two ways to install

| | Microsoft Store | GitHub download |
|---|---|---|
| Where | [apps.microsoft.com](https://apps.microsoft.com/detail/9NKD1BD2RM1X) | [github.com/SujithShalitha/s-converter-releases](https://github.com/SujithShalitha/s-converter-releases/releases/latest) |
| Size | about 240 MB package | about 170 MB installer |
| Warning on first run | none | "Windows protected your PC" (see below) |
| Updates | by the Microsoft Store | by S Converter itself, in the background |

Both are the same app with the same features. Pick one; you don't need both.

## "Windows protected your PC"

The GitHub installer isn't signed with a paid code-signing certificate, so Windows SmartScreen shows a warning the first time. Click **More info**, then **Run anyway**. You only do this once: updates install by themselves afterwards. The Microsoft Store version never shows this warning.

## Updates

- **GitHub version:** S Converter checks for updates in the background, downloads them, and installs them when you're not converting anything. You can also open **Settings → Updates → Check now**.
- **Store version:** the Microsoft Store keeps it up to date.

**About** (bottom of the sidebar) shows your version, your graphics card, and which built-in tools are ready.

## Uninstall

Windows **Settings → Apps → Installed apps → S Converter → Uninstall**. The right-click menu entries are removed too. Your converted files are never touched.
