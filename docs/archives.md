# Archives

## Pack folders and files

Select folders (or files) in File Explorer, press <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>C</kbd>, and pick:

| Choice | What you get |
|---|---|
| ZIP | opens everywhere, built into Windows and macOS |
| 7Z | best compression; opens with 7-Zip or WinRAR |
| RAR | needs WinRAR installed |
| TAR.GZ | the usual archive on Linux and macOS |
| Fast ZIP | no compression, instant, for photos and videos |
| Smallest ZIP / Ultra 7Z | maximum compression, takes longer |
| Locked ZIP | password-protected with AES-256 |
| Locked 7Z / Locked RAR | password-protected, file names hidden too |

With several items selected, the wheel asks: **one archive** or **separate** ones.

## Extract

Select an archive and choose **Extract** (next to the archive, without a pointless extra folder) or **Folder** (into a new folder named after the archive). S Converter opens ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ISO and CAB, and asks for the password when an archive has one.

## Convert archives

An archive can become a **ZIP** that opens anywhere, or a smaller **7Z**.

## Names in other languages

ZIP files with names in Sinhala, Chinese, emoji and other scripts pack and unpack correctly. For 7Z, TAR.GZ and locked ZIP files with such names, install [7-Zip](https://www.7-zip.org); S Converter uses it automatically.
