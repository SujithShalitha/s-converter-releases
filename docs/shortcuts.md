# Keyboard shortcuts

## Anywhere in Windows

| Keys | What they do |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>C</kbd> (changeable) | Quick Convert: the wheel for the selected files, or for the clipboard image when nothing is selected |
| Your **Presets** key (optional) | the wheel, straight on its Presets page |
| Your **Repeat last** key (optional) | redo the last choice for that kind of file, no wheel |

Set them in **Settings → Quick Convert shortcut** and **More shortcuts**. Function keys work too: <kbd>F6</kbd>–<kbd>F9</kbd> on their own, or any function key with <kbd>Ctrl</kbd>, <kbd>Alt</kbd> or <kbd>Shift</kbd>. Windows and other apps already use <kbd>F1</kbd>–<kbd>F5</kbd> and <kbd>F10</kbd>–<kbd>F12</kbd>.

## On the wheel

| Keys | What they do |
|---|---|
| <kbd>Tab</kbd> / mouse wheel | switch Formats and Presets |
| <kbd>1</kbd>–<kbd>9</kbd> | pick a slice |
| Arrow keys, <kbd>Enter</kbd> | choose with the keyboard |
| <kbd>Esc</kbd> | back, or close (while converting: cancel) |
| <kbd>Enter</kbd> when done | close the wheel |

## Page order (images → one PDF)

| Keys | What they do |
|---|---|
| <kbd>Alt</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> | move the selected page |
| <kbd>Enter</kbd> | create the PDF |
| <kbd>Esc</kbd> | back to *One PDF or separate?* |

## In the app

| Keys | What they do |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> in Preview | previous or next file |
| <kbd>Esc</kbd> | close a window such as Preview, Rename or Settings |
| Arrow keys in the watermark designer | nudge the watermark |
