# Watch folders and history

## Watch folders

Point S Converter at a folder, and every new file that arrives is converted automatically.

1. Open **Settings**, and next to **Watch folders** press **Set up**.
2. Press **＋ Add a folder** and choose it, for example *Pictures\Screenshots*.
3. Pick what to do with new files: a format such as **To JPG**, or a preset such as **Private copy** or **Email**.

Results go into a **Converted** folder inside the watched folder, so nothing is moved or overwritten. Each folder has a switch to pause it; ✕ stops watching.

Good uses:

- Screenshots → JPG, smaller for sharing
- Scanner folder → PDF
- Phone photos → private copies without location

Watching works while S Converter runs in the system tray. It waits until a file has finished copying, then converts it. Files that were already in the folder are left alone.

Tools that need a choice or a password (Merge, Lock, Form photo) can't run unattended, so they aren't in the list.

## History

Press **History** at the bottom of the sidebar to see every job, from the app, the wheel, the right-click menu, the clipboard or a watch folder, newest first. **Open** opens the result, **Show** shows it in its folder. Files you've since moved or deleted are marked.

History keeps the last 300 jobs, only on your PC. **Clear history** empties it.
