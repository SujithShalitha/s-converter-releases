# Settings, languages and themes

Press **Settings** at the bottom of the sidebar. Changes apply straight away.

| Setting | What it does |
|---|---|
| Language (top) | 20 languages; **Automatic (Windows)** follows your Windows language |
| Default Output Folder | where files go when *Save at source folder* is off |
| Default Quality | where the Quality slider starts |
| Hardware acceleration | **GPU (auto)** uses your NVIDIA, Intel or AMD graphics card for video and falls back to the processor if needed; **CPU only** never uses it |
| Quick Convert shortcut | the wheel's key, for example <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>C</kbd> or <kbd>F8</kbd>, or off |
| More shortcuts | keys for the wheel's **Presets** page and **Repeat last** |
| Updates | **Check now**; updates otherwise install by themselves |
| Explorer right-click menu | adds S Converter to File Explorer's menu |
| Watch folders | [convert new files automatically](watch-history.md) |
| Theme | Lumen, Aether, Silver or Gel |

## Languages

English, Sinhala (සිංහල), German, Spanish, French, Italian, Dutch, Polish, Portuguese (Brazil), Turkish, Indonesian, Vietnamese, Russian, Ukrainian, Hindi, Thai, Chinese (Simplified and Traditional), Japanese and Korean. The app, the wheel, the tray menu and notifications all switch.

## Themes

- **Lumen** (default): floating glass over a soft sunrise.
- **Aether**: deep purple.
- **Silver**: classic chrome with a blue display.
- **Gel**: pinstripes and glossy gel, like classic Mac OS X.

The Quick Convert wheel follows the theme you pick.
