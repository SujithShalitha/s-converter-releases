# S Converter documentation

Also on the web, with search-friendly pages: **https://sujithshalitha.github.io/s-converter/docs/**

S Converter is a free, all-in-one file converter for Windows 10 and 11. It converts images, video, audio, documents, PDFs and archives on your own PC: nothing is uploaded, there is no account, and it works without an internet connection.

This guide covers every feature. Start with **Install and update**, then **Convert files**, and dip into the rest when you need it.

## Getting started

- [Install and update](install.md): GitHub download or Microsoft Store, and how updates work
- [Convert files](convert.md): the main window, formats, quality and where files are saved

## Working faster

- [Quick Convert wheel](quick-convert.md): convert without opening the app, from File Explorer, the desktop, Open and Save dialogs, or the clipboard
- [Right-click menu](right-click.md): S Converter in File Explorer's menu
- [Presets and recipes](presets-recipes.md): one-click presets, your own presets, and recipes that do several steps at once
- [Keyboard shortcuts](shortcuts.md): every key, in one place

## Getting the result you need

- [Make it fit](make-it-fit.md): a maximum file size (under 100 KB, under 20 MB) and photos for visa, passport and exam forms
- [Trim, watermark and rename](edit.md): edit before you convert
- [PDF tools](pdf-tools.md): merge, split, compress, rotate, number, extract, lock and unlock
- [Archives](archives.md): ZIP, 7Z, RAR and TAR.GZ, with passwords

## Automation and privacy
